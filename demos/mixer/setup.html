AVPlumber mixer setup

Mixer

Unique sources are independent input chains. Scene count is the number of compositions you can switch between; scenes reuse those sources.

Sources

Edit source counts directly. Changing the total redistributes the mix. Switching to HDR selects the balanced mix.

What gets generated?

SDR 4:2:0 uses animated test patterns and colour bars. HLG uses HDR bars and moving highlights. 4:2:2 inputs use packed v210 clips and GPU unpacking; browser sources use the bundled transparent test page.

Each input is independent, but several inputs may read the same generated file. Increasing the source count does not create that many different movies.

Included with every setup

Two generated wipes: diagonal sweep and sliding panels. Each lasts two seconds at the selected FPS. Wipe caching is off.

Outputs and operating limits

Sources and program use the chosen FPS. Source clips stay landscape, even with a portrait program.

Playback requires a Linux NVIDIA host with hardware decode/encode and DMA-BUF support. More sources increase decoder, memory and GPU load; this page does not predict host capacity. Building Docker images needs internet, but these generic assets require no media downloads.
