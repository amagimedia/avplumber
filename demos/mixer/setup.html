AVPlumber mixer setup

Mixer

Unique sources are independent input chains. Scene count is the number of compositions you can switch between; scenes reuse those sources.

Sources

Always the Balanced mix of the unique sources: NVDEC, browser and raw uploads in about equal shares; on a 10-bit canvas half of each 4:2:0 path is HLG.

What gets generated?

SDR 4:2:0 uses animated test patterns and colour bars, as H.264/NVDEC or as raw NV12 frames uploaded to the GPU. Raw upload uses no decoder engine but increases disk and CPU-to-GPU traffic. HLG uses HDR bars and moving highlights, with HEVC/NVDEC or raw P010 upload. 4:2:2 inputs use packed v210 clips and GPU unpacking; browser sources use the bundled transparent test page.

Each input is independent, but several inputs may read the same generated file. Increasing the source count does not create that many different movies.

Downstream keys

Alpha browser graphics keyed over the finished program, above transitions and wipes. Each page is one more browser source and counts against the source and browser limits. Keys start off; switch them on the mixer page.

Outputs

Codec, preset and bitrate per output. Extra AUX share one selection. p1 is the fastest; bitrate does not change NVENC load.
