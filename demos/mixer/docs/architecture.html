How it scales

Cost grows linearly in sources and outputs, and not at all in scenes. What changes during a show costs no nodes; what changes the topology needs a Setup apply, which restarts the mixer and pauses output.

Prewarmed routing, step by step

The demo starts with --prewarm-cut-scene '*': every scene source feeds both compositor slots all the time, and each slot keeps a held picture per source. A take changes only what a slot draws and which slot the selector puts on air.

One direct cut, deadline by deadline

To scale at 30 fps: one output deadline every 33 ms. The cut command lands between two deadlines; slot B already holds scene Y, so Y is on program at the very next deadline.

The AUX PGM cell follows one frame later (pgm_delay_frames 1). The program encoder gets one keyframe on the cut.Structural delays from code only. Measured cut latency: latency.md.
