AVPlumber Live mixer

Code & setup guide

Up to 110 independent inputs at 25/30 fps, or 68 at 50/60 — live Chromium pages, NVDEC clips and raw uploads together — composited on one GPU canvas of a 16 GiB NVIDIA T4 into a 1080p program in either orientation, SDR or 10-bit HLG, cut, faded, dipped and wiped from one page, keyed with up to four downstream graphics, with the whole show described by one JSON document.

  • 110inputs at 1080p30 on one T4: 36 NVDEC + 36 browser + 34 raw NV12 + 4 keys
  • 68inputs at 1080p60: 18 NVDEC + 29 browser + 17 raw + 4 keys, GPU 62–64%, NVDEC 84%, host half idle
  • ~43 msmedian cut latency at 68@60, from the command to the first encoded frame of the new scene
  • 24missed playout deadlines in a 19.5 h run at 68@60 (0.0006%); none in steady state
  • 40real Chromium windows (Electron 44 / Chromium 152), their DMA-BUFs imported zero-copy into CUDA
  • 192scenes per show; cut, fade, dip to colour and GPU-cached media wipes between them

Every browser source is a real Chromium window from the dma-browser demo: its DMA-BUFs are imported straight into CUDA, and the compositor converts packed RGB to the NV12, P010 or P210 canvas in its own draw pass, so pages, NVDEC video and raw uploads mix with no separate conversion. Takes are cut, fade, dip through a colour picked on the control page (a CUDA transition), or a media wipe drawn as one alpha-blended layer by the compositor kernel the scenes use; decoded wipe clips stay cached in GPU memory. Up to four downstream keys — browser pages — go over the finished program, with keyed and clean program feeds, and an aux multiviewer shows PGM, PVW and eight scene tiles, or pages through every source. The canvas is 8-bit SDR 4:2:0, or 10-bit HLG with 4:2:2 or 4:2:0 chroma, encoded as H.264 SDR and H.265 HDR renditions and previewed over WebRTC through Janus; the program is composited once and each rendition re-times and rescales it, so a second output costs an encode, not another composite. The instance's /setup page builds the whole show from source counts, with no JSON editing.
