Real 1080p inputs, no shortcuts

Reviewed 2026-10-06 against mixer-improv at d1dc35fa. Measurements retain their original workload and validation scope; this review does not certify a running deployment.

Current scope. Capacity tests still require independent real-resolution inputs processed at native cadence. The eight small mixed-rate barcoded inputs are a correctness fixture, explicitly not a capacity qualification.

The capacity demo proves what real inputs cost: every source is its own input of at least 1080p25, with its own media, processed on every frame.

Shared test media vs. real inputs

One source, one frame: where each rule applies

At a glance

  • What
    • Each generated source gets its own media: an NVDEC clip, a raw NV12/P010 file or a browser page. No two sources share a file.
    • Its source ID is burned into every frame, on a plate at a spot and orbit phase seeded by that ID. Patterns rotate through a pool by source index.
    • Browser pages render at 1920×1080 and show their ID in the page header.
    • The setup page is 1080p only; the 720p option is gone.
  • Why

    Capacity numbers must describe a real show. Shared files, smaller pictures or replayed GPU frames make every stage look cheaper than it is. A frozen source is visible too: its plate stops moving.

  • Latency

    None. The rule adds no node, queue or wait, so program and command-to-screen latency do not change.

  • Side effects
    • First preparation takes longer: every source renders its own clip.
    • Portrait canvases show the 1920×1080 sources contained, with bars.
    • Headline capacity is lower than a demo with shortcuts would show. That is the point.
  • Cost
    • 0 new nodes, 0 new queues, 0 new threads.
    • Disk and page cache grow with the source count: a raw 1080p NV12 clip at 25 fps is ≈ 155 MB per 2 s, one per raw source.
    • VRAM: nothing held for looped clips.
    • GPU and CPU: full 1080p decode, upload or import on every frame, for every source. This is the honest load.
  • Risk

    If the raw files do not all fit in the page cache, they are read from disk at the combined rate every frame. Old media directories are not pruned; delete them by hand.

  • Switch it off

    No switch for the setup page. It is the capacity demo's ground rule. Custom recipes can still set other generation sizes, or use file and download inputs that several sources read.
