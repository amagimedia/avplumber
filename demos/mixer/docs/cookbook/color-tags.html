8. Tag matching sources instead of filtering them

Correct colour metadata belongs at an existing source fan-out when the source already matches the canvas.

Reviewed 15 October 2026 against e72ff8b4. These pages describe that code and named workload settings; they do not assert what every deployment runs.

Remove a stage only when it does no conversion

Source declarations describe actual colour space, transfer, range and storage. If the automatic colour stage would only stamp tags, the fan-out can stamp them instead, removing a filter node and thread. A source requiring SDR/HDR transfer conversion, range conversion, format normalization or resizing still needs that work.

GPU filter graphs use a constrained worker count instead of building an idle CPU slice pool for each source. This reduces threads and metadata copies without changing the rendered image. The historical 192-source SDR show removed 141 colour-filter threads. Original colour-tag measurements.

Protect picture correctness

Do not change source declarations merely to make a filter disappear. Check HLG/PQ/SDR mixtures, legal/full range, alpha and 4:2:0/4:2:2 behavior with known pixel fixtures. A CPU reduction is invalid if it bypasses required tone mapping or alters the actual colour interpretation.

The separate transparent-pixel fast path skips RGB/HDR math only where alpha proves that pixel contributes nothing. It does not replace tone mapping for visible pixels.
