Multiviewer: 100 sources, 12 at a time

The Multiviewer aux shows every source in pages of 12 equal tiles, and only the 12 on screen send it frames.

Status: Live

At a glance

  • WhatAn aux bus with layout source_pages. It shows every source in equal 16:9 tiles, 12 per page: 2×6 on the portrait 1080×1920 canvas (tiles of about 536×300), 4×3 on landscape. Pages turn every rotate_s (default 5 s). The operator holds a page with mixer.aux_page {bus, page|step|auto}.
  • Why100 sources on one canvas give tiles of about 150×84, too small to judge. Paging keeps tiles readable. Delivering only the page on screen keeps the other 88 sources off the GPU.
  • LatencyProgram: 0 frames. The bus reads sources the M/E already decodes and never delays the program. The aux draws with the main mixer's deadline (latency_ms, 2 frames by default). A page turn keeps the old page on screen until the 12 new sources are ready at the next tick; if they are not ready within 250 ms (or twice the aux latency, whichever is longer), the old page stays.
  • Side effects
    • A page turn closes 12 subscriptions and opens 12; a closed one's queue is cleared.
    • Picking a page stops rotation until ⟳ (or {"auto": true}).
    • Source names exist only in the web UI. The stream itself carries no labels.
  • CostOne compositor pass of 12 tiles per aux frame. One H.264 encoder: +8 % ENC and 48 MB (measured). No PGM tap. One edge per source (capacity 1), but only the 12 shown carry frames. An off-page source costs a lock attempt and an atomic check per frame: no frame, no GPU work, no VRAM. One Python thread turns the pages.
  • RiskIn auto rotation each source is on screen one page in nine, so it returns every 45 s at the default 5 s (derived). A fault on an off-page source shows only when its page comes up. Hold its page, or put it in a scene multiview, to watch it continuously.
  • Switch it offRemove the bus from aux_buses. mixer.aux_page {"bus", "auto": false} stops rotation; {"bus", "auto": true} resumes it.

In the web UI

The viewer header carries the page control ‹ n/N › ⟳: previous, page number, next, auto rotation. [ ] and R do the same. The source names are HTML over the video, placed from the tile geometry the mixer reports, so the encoder never draws text.
